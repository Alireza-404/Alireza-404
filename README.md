### `ABOUT`

</div>

I'm **Alireza Shabani**, a Front-End Developer who enjoys turning ideas into
clean, responsive and interactive digital experiences.

My approach is simple:

**Understand → Design → Build → Refine**

I care about the details that are easy to overlook — structure, spacing,
motion, responsiveness, performance and the overall feeling of an interface.

I'm continuously improving my knowledge of modern Front-End development,
with a particular interest in **React, Next.js, TypeScript, animation and scalable UI architecture**.
